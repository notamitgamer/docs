1. Download the repository (**Code** → **Download ZIP**) or clone it. The frontend is `index.html` plus the `css/` and `js/` folders. Keep them together.
2. Open **`js/config.js`** in a text editor. It's a tiny file with a big `EDIT THIS ONE LINE` banner, so it's hard to miss. Before editing, the line looks like this:

```javascript
const RENDER_BACKEND_URL = ""; // <-- PUT YOUR RENDER URL HERE
```

3. Fill in your Render URL, e.g. `https://your-app.onrender.com` (**no trailing slash**).

That's the only setting needed. As of v4.2.1, the frontend has no Firebase configuration of its own — it authenticates against your Render backend (`/api/verify`) and gets a session token back, then uses that token for every chat/message request over Server-Sent Events. Firebase credentials only ever live on the backend, set in [Deploy the Backend](/whatsapp-logger/deploy-backend).

<Tip>
Older versions kept `RENDER_BACKEND_URL` inside `index.html`. If you're updating an existing deployment, set it in `js/config.js` now and upload the whole folder.
</Tip>

## Frontend file layout

```text
index.html        page markup (sidebar, chat area, modals)
css/              themes, layout, modals
js/config.js      the only file you need to edit
js/*.js           app code, split by feature (boot, lock screen, SSE sync, chat UI, calendar, ...)
sw.js             service worker (offline support)
manifest.json     PWA manifest
```

<Warning>
The scripts are plain `<script>` files that share one global scope, so the load order in `index.html` matters. If you add a file, add it to the list at the bottom of `index.html` and to `ASSETS` in `sw.js`.
</Warning>

## Deploy the frontend

Host the whole frontend folder on any static host:

- **Firebase Hosting** (recommended): `firebase init` → Hosting → select `public` directory → copy `index.html`, `css/` and `js/` there → `firebase deploy`
- **GitHub Pages**: enable Pages in your repo settings
- **Netlify / Vercel**: drag and drop the folder containing `index.html`

Continue to [Usage](/whatsapp-logger/usage).
