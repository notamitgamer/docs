Githrun stores configuration and cache files in your home directory:

| Path | Purpose |
|---|---|
| `~/.githrun/config.json` | Tokens, bookmarks |
| `~/.githrun/cache/` | Cached API responses |
| `~/.githrun/bin/` | Installed tools |
